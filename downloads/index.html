Testudo and OpenTestudo have the same agent. Select the one that fits your work.

Testudo

The Mac App Store version. It runs in the App Sandbox. The agent works only in the folders that you select.

OpenTestudo

The same app with no limits. It has a Developer ID signature, and Apple notarizes it. It updates itself.

System requirements

  • macOS 27 or later
  • A Mac with Apple silicon
  • We recommend 32 GB of memory for the local models
