Ask. The agent does it.

Testudo is an agent app for coding and for work on your Mac. You chat with the agent, and it does the task.

  • Local models

    The models run on your Mac. Testudo selects models that fit your Mac and downloads them one time. Your prompts and your files stay on your Mac. There is no cost for each token.

  • An agent that does the work

    Tell the agent what you want. It reads and changes files, uses git, runs code, and searches the web. It can give parts of a task to subagents.

  • Rollback

    Testudo keeps snapshots of the files that the agent changes. Ask the agent to undo a change, and it rolls back the files.

  • Skills and agents

    Ask the agent to write a skill or a new agent for you. Agents and skills are folders in iCloud, so each of your Macs has them.

  • MCP servers

    Connect the agent to MCP servers and give it more tools.

  • A native Mac app

    Testudo is a SwiftUI app. It has windows and tabs, a command palette, and light and dark appearance.

Coming

The next releases

These features are not in the first release. We build them next.

  • Kanban board

    Each folder gets a board. The agent makes a plan as tasks on the board. You start a task, and a subagent does it. Column triggers move the work from column to column.

  • Timeline of changes

    A timeline shows each checkpoint of the agent and the changes of each file. Select a checkpoint and roll back to it.

  • Rules

    Write rules in plain words. Before code runs, a local model examines it against your rules and stops actions that a rule denies.

  • iPad and iPhone

    Connect to the agent on your Mac from your iPad or iPhone.
